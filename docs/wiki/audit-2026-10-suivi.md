## Règles du chantier

Préambule commun (`docs/audits/PROMPTS-GOVERNOR-FACTURAPRO.md` § Préambule commun), rappelées ici pour chaque lot :

- **Pipeline obligatoire**, dans cet ordre : Graphify (`query` / `explain` / `path` / `affected`) → analyse des dépendances → plan numéroté → délégation aux sous-agents (backend / frontend / database / architecture / qa) via le Task tool → QA → STEP 5 `graphify update .` → STEP 6 wiki. Le Governor n'écrit jamais le code d'implémentation lui-même.
